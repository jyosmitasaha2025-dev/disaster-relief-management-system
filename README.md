# Disaster Relief Management System

A Java, MySQL, and JDBC-based disaster relief management system designed to manage beneficiaries, relief camps, relief resources, medical cases, assistance requests, SOS emergencies, public notices, and administrative operations.

## Features

- Beneficiary registration and management
- Relief camp management
- Relief resource management
- SOS emergency request management
- Assistance request management
- Medical case management
- Public notices
- Administrative dashboard
- CRUD operations using MySQL
- Java backend connected to MySQL using JDBC

## Technology Stack

- Java
- MySQL
- JDBC
- HTML
- CSS
- JavaScript

## System Architecture

```text
Frontend
   ↓
Java Backend
   ↓
JDBC
   ↓
MySQL Database

```

## Database

The system uses a relational MySQL database containing tables for:

- Beneficiaries
- Relief Camps
- Relief Resources
- Disasters
- Assistance Requests
- SOS Requests
- Medical Cases
- Public Notices
- Activities
- Audit Logs

## CRUD Operations

The system demonstrates the four fundamental database operations:

| Operation | SQL |
|---|---|
| CREATE | `INSERT` |
| READ | `SELECT` |
| UPDATE | `UPDATE` |
| DELETE | `DELETE` |
